## 冻结的对象与设置

模型为原 Qwen3.5-27B、TP2，BF16 权重和激活、FP32 SSM、HF32 关闭；官方和 compact 的状态算法、Q4 内核和权重保持冻结。304 个 decoder 投影共同使用 NZ29，LM head 使用同一官方实现。质量入口采用 eager 执行，不能外推为长上下文 ACLGraph 服务资格。

本文“官方”指同一离线 Q4 生成适配器中的官方 dense recurrence 对照。两侧均独立生成，没有使用普通官方服务得分或 teacher-forcing 结果替代 compact 任务评测。

使用 ModelScope `evalscope/aime26` 全部 30 题，revision `12ae93b463353acd4d272dbbc7dbecbcfb902642`，数据 SHA256 为 `52822957957a3f577d1e9706c36a66a8108a3f99b6aff424cfb72dff0094a9ee`。工具固定为 EvalScope 1.13.0、AIME adapter evaluation_version v1.1、Math-Verify 0.9.0。逐字使用该版本 AIME prompt、checkpoint 聊天模板，enable_thinking=True。

查看正式输出前固定 greedy（temperature=0、top_p=1、top_k 禁用、penalty 中性）、seed=42，每题最多 81,920 个输出 token，max_model_len=82,944；EOS=[248046,248044]，无文本 stop，不因 boxed 答案提前停止。模型卡推荐采样但未禁止 greedy；本轮使用 greedy 减少采样变化，不用于复现模型卡成绩。

固定按题序分成 8/8/8/6 四组，两侧分别从零状态完成相同 prompt 的 prefill。各侧只依据自身历史用安装版 vLLM ngram proposer 给出最多 3 个候选，由 Q4 logits 的 argmax 顺序验证，使用真实接受前缀推进 conv、SSM、KV。未提出的填充 token 不能被接受，EOS/预算可在接受前缀内部结束。终末提交选择每个请求的最后实际接受数；末输出 token 保留普通 decode 的尚未计算语义。生成 manifest 不含参考答案，参考答案仅进入离线评分器。

## 与原证据并列的结论和边界

原 hidden NRMSE≤0.005 检查失败仍保留。FP32 首步诊断中，起点与 owner/状态映射一致，layer0 recurrence 约 2e-6 局部差异经后续 BF16 运算放大，最终 hidden NRMSE 为 0.0118161；未找到可作有限修复的明确实现错误。FP16 排查保持结束。

原真实文本初筛仍失败：平均 KL=0.00556279（门槛 0.001），TV P99=0.05123891（门槛 0.05），worst-owner ΔNLL=0.12216764（门槛 0.05），该 owner 局部 PPL 增加 12.99435%；整体 PPL 仅增加 0.0113772% 不覆盖这些失败。

已有同算法 ready/delayed 状态一致性和闭合耗时均值改善 4.801135% 作为旧证据保留。该计时仅覆盖 decoder+finalnorm，不含 LM head、采样或服务，也不属于多图独有收益。固定轨迹的该项改善不等于自主生成任务总耗时改善。本轮不增加性能轮次。

本轮仅可陈述：在该固定 AIME26 配置下，compact 的净题数变化为 -3，官方独对 3 题，compact 独对 0 题。30 题的一次配对对小幅任务差异约束很弱，没有重复采样或其他任务证据，不能据此把误差认定为普遍可接受。任务观察与原分布/局部退化分别成立。本轮到此收口，不增加轮次或调整解码搜索。
