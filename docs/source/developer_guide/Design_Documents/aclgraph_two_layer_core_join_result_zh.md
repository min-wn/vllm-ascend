# 接入真实 FIA 上游后的两层验证

日期：2026-10-20（北京时间；远端日志为 10 月 19 日 UTC）。

## 1. 结论

**输入投影切分、core 前合批的收益在这次完整两层小实验中仍存在，
但设备时间仅改善 0.78%～1.72%，墙钟改善 0.72%～2.05%。**
三轮均为正结果；样本较少，不能宣称统计显著性、尾延迟改善或全模型收益。

本次把此前省略的第 3 层输入 Norm、QKV、QK Norm/RoPE、KV 写入、FIA、gate、
O 投影和归约全部接回；它的真实输出接入第 3 层 MLP，随后进入第 4 层完整 GDN/MLP。
每次 replay 的 FIA 真实主机长度 update、元数据 H2D、最终流汇合均计时。

两层入口仍为受控合成 hidden/residual，KV 前缀由真实投影生成的合成输入初始化，
没有运行用户 prompt 的完整模型 prefill。此处“真实上游”指真实算子与状态执行，
不表示端到端模型输入分布或完整生成质量已经得到验证。

## 2. 对照和结果

条件与前轮相同：910B3、Qwen3.5-27B BF16、TP2、Q4、种子选出的 B98，
默认图容量 400 个词元，合法切分 200+200。没有新增专用容量。

三个控制共享完整 FIA 上游、NZ 权重、ready-tile compact GDN 后端：

- Padding：整批前层 Down、整批下一层投影/core。
- 切分等待：拆前层 Down/归约和下一层输入投影，core 前合批；等待两个归约都完成再进入下一层。
- 切分提前：同样算术和汇合位置，A 归约完成即可提前进入下一层输入投影。

每模式三轮，每轮六个有效样本；轮间正反交替顺序。
逐样本取双 rank 较慢耗时，再计算轮内中位数。单位为微秒。

| 轮次 | Padding 设备时间 | 切分等待 | 切分提前 | 提前比等待减少 | 提前比 Padding 减少 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1 | 3909.16 | 3979.44 | 3851.78 | 127.66 | 57.38（1.47%） |
| 2 | 3889.46 | 3988.67 | 3859.19 | 129.48 | 30.27（0.78%） |
| 3 | 3867.81 | 3962.48 | 3801.18 | 161.30 | 66.63（1.72%） |

墙钟中位数：

| 轮次 | Padding | 切分提前 | 减少 |
| --- | ---: | ---: | ---: |
| 1 | 4071.11 | 3998.55 | 1.78% |
| 2 | 4037.92 | 4008.73 | 0.72% |
| 3 | 4025.76 | 3943.35 | 2.05% |

每次计时前恢复相同的一致状态；快照恢复和 CPU 描述符构建不在计时内。
计时内重新复制固定 CPU 描述符到设备，解析当前真实长度、提交图、执行 FIA task update，
并等待图和 update 流结束。因此不把这组静态 B98 重复测量称为完整动态服务轨迹。
另有 B98→97→99、接受前缀 1→2→3 的动态元数据/状态资格检查。
这组受控步序也不等同于真实请求生命周期或连续生成正确性验证。

## 3. Profile 是否还支持原来的解释

六份 trace 的清点结果一致：

| 路径 | MatMul | AllReduce | FIA | GDN solve | commit |
| --- | ---: | ---: | ---: | ---: | ---: |
| Padding | 9 | 4 | 1 | 1 | 1 |
| 切分路径 | 12 | 5 | 1 | 1 | 1 |

每条图注册且每次 replay 解析一个真实 FIA update task，核对其主机 KV 长度与本步一致。
完整两层中下一层输入 GEMM 仍不早于前层 Down B GEMM 完成。
切分提前的 A 输入 GEMM 与最后一块归约重叠 118.30～120.68 微秒，
加上输入 Norm/前处理后，主流覆盖该归约约 142.02～142.42 微秒。
切分等待对应的重叠为零。
六次 core 前合批复制共约 38.26～38.44 微秒，仍没有被挪出计时。

因此，接入 FIA 并未破坏这一局部并行窗口。
相比前轮的局部段，本轮增加了共享工作，两层 Padding 耗时约 3.87～3.91 毫秒，
而前轮约 2.84 毫秒，收益比例自然受到稀释。
但是绝对收益从前轮约 61～69 微秒变为本轮约 30～67 微秒，
不能只用分母增加解释全部变化；输入分布改变、运行波动、主机提交和资源状态都可能影响。
当前证据没有将这些因素进一步分离，不能断言存在某个已经定位的新退化算子。

本次 profile 仍有跨 rank 到达偏差：前层 O 归约在 rank1 可达约 519～778 微秒，
rank0 约 247 微秒。故不能用 profile 总跨度替代独立计时，也不能把这些异常等待
当作可自由隐藏的固定通信预算。profile 只用于清点、局部依赖和重叠分析。

## 4. 正确性证据与剩余限制

新增对照：直接调用官方完整第 3 层、再调用官方完整第 4 层，
与 Padding 的分段执行比较，输出和全部状态严格相等。
该对照使用共同的 compact GDN 后端，验证的是分段连接与布局，
不是重新验证 compact 后端相对原生 dense 状态的全部语义。

三个路径、两个 rank 的三步检查均通过：

- 同调度 eager/replay 的输出、卷积、compact 状态和 FIA KV 严格相等。
- 切分等待与切分提前严格相等。
- GDN inactive/null 保持不变，dense 初始化源没有被写回。
- FIA 仅允许本步有效 slot 改变，其他缓存位置保持不变。
- 输出和状态均有限。

切分与 Padding 的 FIA key/value 三步均严格一致。
下游 hidden NRMSE 为 0.00254～0.00287，最大绝对差为 0.03125～0.09375，
按原阈值 `0.02 + 0.02 * abs(reference)` 没有 hidden 失败元素。
第 0 步 residual 仍有一个元素超出阈值，最大绝对差 0.25；其余两步无 residual 阈值失败。
两个 rank 诊断一致，没有放宽阈值，也不能据此宣称完整精度或生成质量准入通过。

## 5. 对当前方案的判断

已经从“合成的已归约 attention 输出后接一个局部段”推进到
“完整 FIA 层 → 完整 GDN 层”的有限规模证据，且真实 update/H2D 已包含。
这比前轮更接近实际依赖，但当前仍只覆盖一个层对和一个计时 batch。
没有理由将约 1% 的两层改善包装为显著端到端提升。

下一步应将此边界做成可开关的执行模块，在完整模型的少量对应边界上验证累计效果，
而不是先按层数线性外推收益。该接入仍需保持状态生命周期、图容量与公共优化对称，
并补齐跨形状数值差异的准入判断。
若先做性能筛选，可优先收集一次完整路径 profile 判断共同开销和可重复窗口；
不立即扩展模型、卡数、容量的大矩阵。

机制归因仍然是“请求分组降低依赖粒度，按窗口限制切分范围并及时合批”。
普通微批、跨层流水和计算通信重叠不能声称首创；
多张图也不是必要条件，本实验把请求依赖放在同一张 UpdatableGraph 内表达。
当前成果是一个可解释的小幅正结果，距离完整毕设算法与创新性证据仍有工作。
